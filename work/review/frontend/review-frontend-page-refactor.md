# 프런트 페이지 리팩토링 검토 — 리뉴얼로 승계

- 재검토일: 2026-10-25
- 상태: 공통 UI·반응형·대시보드 분리와 보고서 제거 구현·로컬 검증 완료. 실제 기기·운영 인증 회귀는 상위 리뉴얼의 잔여 항목으로 관리.
- 후속 기준: [리뉴얼 검토](../common/review-project-renewal.md), [리뉴얼 계획](../../todo/common/todo-project-renewal.md)

## Scope

- 페이지 책임 축소, 반복 로직·타입·아이콘·CSS 공통화 기준을 재사용한다.
- 디자인·모바일 개편과 보고서 제거에 맞춰 과거 우선순위·제외 조건을 정리한다.

## Summary

- 과거 문서의 핵심인 “줄 수보다 책임 혼합을 기준으로 분리”를 유지한다.
- 관리자 일일보고는 리뉴얼 3단계에서 제거했다.
- 과거 페이지 줄 수·미구현 설명·점수는 최신 코드의 검증 결과로 사용하지 않는다.

## Findings or Scores

- [공통 UI](../../../gw-home-ui/components/common)에는 헤더·사이드바·모달·버튼·토스트 등의 기반이 있다.
- [관리자 feature](../../../gw-home-ui/features/admin)에는 계정 관리 composable·폼·테이블·모달이 존재한다. 과거 “모든 로직이 페이지 한 곳에 있다”는 진단을 그대로 적용하지 않는다.
- [대시보드](../../../gw-home-ui/pages/dashboard/index.vue)는 `DashboardWorkspacePage`를 조합한다. 보고서 호출·집계·바로가기를 제거하고 할 일 요약을 연결했다.
- [전역 스타일](../../../gw-home-ui/assets/styles/main.css)은 디자인 토큰·레이아웃·모션 파일을 불러온다. 공통 제목·조회 상태·페이지 이동과 모달 포커스/스크롤 동작을 공유한다.
- OTP·공지·계정 관리 등 유지 기능은 동작을 보존한다. 이 문서 정리에서 해당 흐름 전체를 재검증하거나 재작성 대상으로 확정하지 않았다.

## Recommended Next Actions

1. 실제 구현 시 대상 화면의 현재 책임·중복을 다시 확인한다.
2. util·composable·feature UI·타입·아이콘·공통 스타일을 적절히 분리하고 페이지는 조합 중심으로 유지한다.
3. 디자인·반응형 개편은 상위 계획 1단계, 대시보드 TODO 연결은 2단계, 보고서 제거는 3단계에서 관리한다.
4. 공통화 목적만으로 인증·권한 정책이나 유지 기능을 변경하지 않는다.
