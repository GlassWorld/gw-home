# 주간보고 공개 조회 검토 — 리뉴얼 제거 계획으로 대체

- 정리일: 2026-10-25
- 상태: 기존 기능 확장 검토 종료. 리뉴얼 3단계에서 코드 제거와 로컬 검증 완료.
- 후속 기준: [리뉴얼 검토](../common/review-project-renewal.md), [리뉴얼 계획](../../todo/common/todo-project-renewal.md)

## Scope

- 과거 요청: 내 주간보고와 사용자별 공개 주간보고 조회를 분리하는 기능.
- 현재 요청: 개인·공개·관리자 보고 기능을 제거하고 개인 할 일 중심으로 리뉴얼한다.

## Summary

- 과거 문서의 “공개 조회 API와 화면이 없다”는 설명은 제거 직전 구현과 달랐다. 현재는 리뉴얼에 따라 해당 코드가 제거된 상태다.
- 공개 조회 구현이 확인되어 신규 개발 제안은 종료한다. 해당 기능은 리뉴얼 3단계에서 제거했다.

## Findings or Scores

- 기존 `WeeklyReportController`의 `/open/members`, `/open`, `/open/{uuid}`와 개인·공개 보고서 화면을 제거했다.
- 공개 조회뿐 아니라 대시보드 최근 보고, 즐겨찾기, 일일보고 원본 조회와 초안 생성도 제거 영향에 포함된다.
- 보고서 API 404·권한 경계, URL 종료 안내와 즐겨찾기 정리를 검증했다. 검증 범위·제약은 상위 계획의 3단계 기록을 따른다.

## Recommended Next Actions

1. 공개 조회 기능을 추가하거나 확장하는 이전 권고를 실행하지 않는다.
2. 제거된 기능의 신규 유지·확장 작업을 시작하지 않는다.
3. 보관된 보고서 데이터의 이관·물리 삭제는 별도 요청과 정책 확정 후 진행한다.
