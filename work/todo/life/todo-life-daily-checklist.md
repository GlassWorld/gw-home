## Done criteria
- 오늘을 기본 선택하고 매일 항목을 간단히 등록·체크·취소할 수 있다.
- 새로고침 후 기록이 유지되고 어제와 오늘의 체크가 독립적이다.
- 월 이동과 날짜 선택으로 과거 기록을 확인·수정한다. 미래 날짜의 완료는 저장하지 않는다.
- 월 경계·윤년·시차에서 날짜가 어긋나지 않는다.
- 타인 항목은 조회·수정할 수 없고 기존 업무·단발성 일상 집계가 바뀌지 않는다.
- 좁은 모바일에서도 캘린더·긴 제목·체크 조작이 가능하다.
- 실제 DB 적용 여부와 미실행 검증을 명확하게 보고한다.

## Implementation
- `LifeDailyController/Service/Convert/Dtos`, `LifeDailyMapper/XML`, 항목 VO와 완료 조회 JVO를 추가했다. 기존 BaseVo의 공통 식별자를 재선언하지 않고 UUID를 사용하며, 기존 계정 조회의 getIdx 호환성을 유지했다. API는 내부 키를 반환하지 않는다.
- `tb_lf_daily`, `tb_lf_daily_check`와 기존 DB용 `life-daily-migrate.sql`을 추가하고 빈 스키마용 `docs/all-ddl.sql` 트랜잭션 안에 동기화했다.
- 기존 일상 화면에 매일/일반 보기 전환과 캘린더·체크리스트를 조합했다. 날짜별 기록은 서버에 저장하며 체크 성공 후 화면에 반영한다. 일반 할 일의 기존 분류 링크는 해당 보기로 연결한다.
- 종료는 오늘까지 포함하며 내일부터 제외한다. 과거 체크는 유지·수정 가능하고 미래 날짜는 서버에서도 거부한다.
