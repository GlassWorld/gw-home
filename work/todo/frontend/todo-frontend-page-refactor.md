# 프런트 페이지 리팩토링 계획 — 리뉴얼에 통합

- 정리일: 2026-10-25
- 상태: 공통화·대시보드 분리·보고서 제거 구현과 로컬 검증 완료. 실제 기기 및 운영 인증을 포함한 전체 회귀는 상위 리뉴얼 계획에서 관리.
- 검토: [프런트 리팩토링 재검토](../../review/frontend/review-frontend-page-refactor.md)
- 실행 기준: [리뉴얼 계획](../common/todo-project-renewal.md)

## Goal

- 페이지 책임을 줄이고 모바일·PC 공통 디자인을 재사용 가능한 컴포넌트와 스타일로 적용한다.

## Scope

- 기존 util·composable·폼·모달·타입·아이콘 분리 원칙을 유지한다.
- 디자인 전면 개편 제외 조건은 새 리뉴얼 요청에 따라 해제한다.
- `admin/daily-reports`는 리뉴얼 3단계에서 제거했다.
- 인증·OTP·공지·게시판·금고·관리자 계정 등의 기존 동작은 유지한다.

## Current State

- 관리자 feature와 공통 UI 등 일부 분리가 이미 코드에 존재한다.
- 과거 고정 줄 수와 “아직 모두 페이지에 있음” 설명은 현재 상태로 사용하지 않는다.
- 대시보드 페이지는 feature를 조합하고 TODO 요약을 표시한다. 보고서 연동은 제거했다.

## Done Criteria

- 줄 수만을 목적으로 분리하지 않고 페이지·feature·공통 UI 책임을 구분한다.
